⏱️ Check
Check is a background session tracker built for developers. Keep a pulse on your coding flow, visualize file changes, and map out exactly where your codebase evolved during deep work.

🎯 The Problem & Solution
Ever lost track of which files you touched during a long coding sprint? Or spent hours hunting down the source of a new bug because you lacked context?

Check runs quietly in the background. When your session timer ends, it delivers a clear, visual summary of your file edits, line additions, and deletions, transforming raw activity into actionable insights.

✨ Features
⏱️ Focus Timers: Set custom sessions (from 1-hour sprints to multi-day marathons) for uninterrupted coding.

📊 Visual Analytics: Get instant charts and heatmaps showing exactly which files had the most activity.

💾 Quick Checkpoints: Manually save the state of your workspace at any moment with a single click.

🔍 Live Tracking: Monitor active Git branches and exact line modifications on the fly.

🚀 Getting Started
Open your project workspace.

Head to the Session tab and set your desired focus time.

Click Start Session and dive into your code!
